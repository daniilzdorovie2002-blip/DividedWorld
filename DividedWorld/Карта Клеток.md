При любой отправке работников, войск, или жителей к соседней клетке показывать процесс продвижения, делать его не моментальным. Визуально отображать на карте такие перемещения. Сделать в UI список всех текущих передвижений.
**Стоимость перемещения в зависимости от лора (пример):**
- 0.5 игровой день на сборы (в любом лоре)
- 1 дня на прохождения одной клетки (в лоре, где средний размер), +1 день если большой ло

**Ресурсы на карте**
ПРИМЕЧАНИЕ - в зависимости от лора на клетке может быть несколько источников ресурсов. Мелкий мир 2-3 ресурса, средний мир 3-5 ресурса, большой 5-7 ресурса
- Лес - каждая иконка имеет количество ресурсов в ней. Три типа леса: **глубокий лес** (1000 ед.), **средний лес**(400 ед.) и **редколесье**(150 ед.)
  В процессе вырубки из 401 ед. в 399 ед. менять тип леса на карте (из глубокого в средний). У каждого вида по 3 типа иконок. В лес направляются работники из зданий **Пункт лесозаготовителей** для его вырубки, **Пункт охотников** для охоты и **Пункт собирателей**. На каждый лес можно назначить бесконечное число рабочих из **Пункт лесозаготовителей** и только один пункт **Пункт охотников** или **Пункт собирателей** со всеми его работниками.
- Поле - земля с плодородной землёй для постройки поля для скота или поля для обработки (если это Главная клетка владельца). 
  10 видов иконок. в поле направляются работники из **Пункт охотников** для охоты и **Пункт собирателей**. На каждое поле может быть назначен только один пункт со всеми его работниками.
- Шахта с залежами - место для постройки шахты. В шахте случайное число руды от 200 до 500. Типы шахт с **камнем** или с **железной рудой**.
  3 вида иконок на каждый тип залежи. В будущем организовать через Здание **Гильдии шахтеров** походы на соседние клетки за выработкой шахты
- Вход в [[Подземелья]] - для каждого уровня своя иконка.
- [[Типы поселений NPC]] - для каждого типа поселения 3 вариации иконок.
